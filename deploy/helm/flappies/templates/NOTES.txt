Next steps (see docs/KUBERNETES.md for the full walkthrough, and
docs/DEPLOYMENT.md#tenant-onboarding-central-zitadel for the tenant
onboarding runbook):
  1. If you haven't already, provision this tenant in the central ZITADEL
     (Organization + Project + OAuth app + service user) with:
       ./deploy/scripts/provision-tenant-zitadel.sh
     or do the equivalent steps by hand in the ZITADEL console — ideally
     BEFORE this install, so secrets.zitadel* is already correct above.
  2. If it wasn't provisioned yet, put the resulting client secret / PAT /
     client credentials into secrets.zitadel* (or your existingSecret), then
     `helm upgrade` again.
  3. Link an app admin: run the equivalent of
     deploy/scripts/bootstrap-app-admin.sh against the app Postgres
     (kubectl exec into the {{ include "flappies.fullname" . }}-postgres-app-0 pod, or
     port-forward it and run psql from your machine).
  4. (Optional) Set observability.metrics.pushgatewayUrl / observability.logging.lokiUrl
     to point at your own Prometheus Pushgateway / Loki, and support.smtp.* to
     enable the admin "Support / feature request" form. Flappies only supports
     the connection between this app and those services — you're responsible
     for running/self-hosting them (or using a managed provider).
